# Start3D — 3D-печать в Баку (демо)

Демо-сайт сервиса 3D-печати по запросу: заказ по STL или по фото, живой эфир печати, трекер заказа, уведомления в Telegram или на email, панель оператора (принтеры, склад филамента, статистика).

Один файл `index.html`, без сборки. Языки: AZ / RU / UK / EN.

Это прототип: печать, оплата, камера и уведомления имитируются, данные хранятся в браузере каждого устройства.
