# Мост мастерской Start3D

Программа на компьютере в мастерской. Читает статус печати и кадры камеры с принтеров в локальной сети и отправляет их на сервер Start3D. Компьютер должен быть в той же Wi-Fi сети, что и принтеры.

## Установка на Windows

1. Установите **Node.js LTS** с https://nodejs.org (кнопка LTS, всё по умолчанию).
2. Скачайте репозиторий: на странице GitHub → Code → Download ZIP, распакуйте. Нужна папка `bridge`.
3. В папке `bridge`: клик правой кнопкой по пустому месту → «Открыть в терминале», затем:
   ```
   npm install
   copy config.example.json config.json
   notepad config.json
   ```
4. Заполните `config.json`:
   - `bridgeKey` — тот же длинный ключ, что вы добавили в Cloudflare как секрет `BRIDGE_KEY`;
   - `serial` — серийный номер (Настройки → Устройство);
   - `accessCode` — 8 цифр Access Code (Настройки → Сеть/WLAN).
   Этот файл никуда не отправляйте: в нём пароль от принтера.
5. Запуск:
   ```
   node bridge.mjs
   ```
   В окне должно появиться «MQTT подключён» и «камера подключена». Не закрывайте окно.

Чтобы ноутбук не засыпал: Параметры → Система → Питание → «Переводить в спящий режим» → Никогда (при питании от сети).

## Если камера не подключилась

Мост сначала пробует порт 6000, потом RTSPS. Для второго способа нужен ffmpeg: `winget install ffmpeg`, затем перезапустите мост. Также проверьте в настройках принтера пункт про LAN / Liveview.

## Второй принтер

Добавьте в `printers` ещё один блок с `"id": "a1-2"` и его адресом, серийным номером и кодом. Допустимые id: `a1-1`, `a1-2`, `k2`, `ender`.
