# Мост мастерской Start3D

Программа на компьютере в мастерской. Читает статус печати и кадры камеры с принтеров в локальной сети и отправляет их на сервер Start3D. Компьютер должен быть в той же Wi-Fi сети, что и принтеры.

## Установка на Windows (5 минут)

1. Скачайте репозиторий: https://github.com/xsamikx-creator/Start3D → зелёная кнопка **Code** → **Download ZIP**, распакуйте, например, в `C:\Start3D`.
2. Откройте папку `bridge` и дважды кликните **start.bat**.
   - Если Node.js не установлен, он поставится сам (подтвердите установку). Потом запустите `start.bat` ещё раз.
   - Откроется Блокнот с `config.json`. Впишите:
     - `bridgeKey` — тот же ключ, что в Cloudflare в секрете `BRIDGE_KEY`;
     - `serial` — серийный номер (Настройки → Устройство);
     - `accessCode` — 8 цифр Access Code (Настройки → Сеть/WLAN).
     Сохраните и закройте Блокнот. Этот файл никуда не отправляйте: в нём пароль от принтера.
3. В окне моста появится «MQTT подключён» и «камера подключена». Окно не закрывайте — его можно свернуть.
4. Чтобы мост запускался сам после включения ноутбука, один раз запустите **autostart.bat**.

Ноутбук не должен засыпать: Параметры → Система → Питание → «Переводить в спящий режим» → Никогда (при питании от сети).

## Если камера не подключилась

Мост сначала пробует порт 6000, потом RTSPS. Для второго способа нужен ffmpeg: `winget install ffmpeg`, затем перезапустите мост. Также проверьте в настройках принтера пункт про LAN / Liveview.

## Второй принтер

Добавьте в `printers` ещё один блок с `"id": "a1-2"` и его адресом, серийным номером и кодом. Допустимые id: `a1-1`, `a1-2`, `k2`, `ender`.

## Обновления

`start.bat` при каждом запуске сам скачивает свежий `bridge.mjs` с GitHub (если файл скачался и он рабочий). `config.json` не трогается. Чтобы получить обновление, просто закройте окно моста и запустите `start.bat` снова.

## Эфир с задержкой

Пока принтер печатает, мост записывает камеру кусками по 4 секунды (до 5 кадров/с) и отправляет их на сервер. Сайт показывает эфир плавно, с отставанием ~15 секунд.

## Отдельная IP-камера (плавное видео)

Камера с RTSP (например Imou Cue 2) даёт настоящее видео 15 кадров/с. Нужен ffmpeg: `winget install Gyan.FFmpeg`.
Добавьте принтер в `config.json` с полем `video` — адрес RTSP камеры. Если у принтера нет своего подключения
(ip/serial/accessCode), запись включается, когда на сайте у этого принтера есть заказ в статусе «печатается».
Дополнительно: `videoWidth` (по умолчанию 1280), `videoFps` (15), `videoKbps` (1000).

## Таймлапсы
Пока принтер печатает, мост снимает один кадр на каждый новый слой (если принтер не сообщает слои — кадр раз в 8 секунд).
После печати он склеивает кадры в ролик MP4 на 10–20 секунд и отправляет его на сайт. Ролик попадает в чат операторов,
а когда заказ «готов», бот сам присылает его клиенту. Публичные и бесплатные печати показываются в разделе «Таймлапсы недели».

Копии роликов лежат в папке `timelapses` рядом с мостом и хранятся 30 дней. Если интернета не было, мост дошлёт ролик позже сам.
Настройки в `config.json`: `"timelapseSeconds": 8` — интервал кадров без слоёв, `"timelapseKeepDays": 30` — сколько дней хранить копии,
`"timelapse": false` у принтера — не снимать таймлапс для него. Отдельный канал для роликов: переменная `TL_CHAT_ID` в Cloudflare.

## Автопечать
Оператор жмёт «🤖 Автопечать» на карточке заказа (в Telegram или в панели) и выбирает принтер. Мост:
1. берёт файл модели заказа (STL/3MF/OBJ/STEP до 20 МБ; файл можно прислать ответом на карточку заказа);
2. выбирает слот AMS lite с нужным материалом и ближайшим цветом;
3. нарезает модель в Bambu Studio без окна: профиль «Bambu Lab A1 0.4 nozzle», «0.20mm Standard @BBL A1»,
   ваш калиброванный профиль пластика (если он есть), поддержки tree(auto) только там, где нужны;
4. сверяет вес с заказом — если вышло больше чем на 30%, спрашивает оператора;
5. отправляет файл на принтер по локальной сети и запускает печать. Заказ сам переходит в «Печатается».

Перед кнопкой стол должен быть пустым. На принтере должен быть включён LAN-режим и «Режим разработчика»
(Настройки → Сеть/LAN only → Developer mode), иначе прошивка не принимает команды печати от моста.
Настройки в `config.json` (необязательно): `"slicer": { "exe": "…\\bambu-studio.exe", "process": "0.20mm Standard @BBL A1",
"supports": "auto" | "off", "orient": 0 | 1, "colorTolerance": 70, "filaments": { "PETG": "имя профиля" } }`.

## Принтер сменил IP
Мост сам слушает сеть: принтеры Bambu сообщают о себе (как для Bambu Studio) со своим серийным номером и адресом.
Если адрес изменился, мост записывает новый IP в `config.json` и перезапускается. Windows при первом запуске
может спросить разрешение для Node.js в сети — нажмите «Разрешить» (частные сети).
